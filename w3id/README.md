# efo-plutchik

Permanent identifier for **EFO-Plutchik**, an EFO-compatible ontology module for Plutchik's wheel of emotions.

- Namespace: `https://w3id.org/efo-plutchik#`
- Version IRIs: `https://w3id.org/efo-plutchik/<version>` (e.g. `/0.5.0`)
- Source and documentation: https://github.com/kotafuse-labs/efo-plutchik
